    The apps I always want

    i

    This is your own list, kept separately from any backup. On a machine with nothing on it, open Flat, come to this tab and press Install — every app on the list goes on in one go. Apps already here are skipped.

    Each app is Fresh or Keep settings. Fresh apps install clean. Keep settings apps install and then get their settings back from a backup — the one named just above the list, which Flat finds on its own if it sits beside the AppImage or in Downloads. Only apps this Install actually puts on get their settings back: an app already on the machine is never touched. Tick several and use the buttons above the list to mark or remove them together.

    You only need an app's ID, the reverse-web-address name like org.mozilla.firefox. There is no separate Flathub location to find: the search box below turns a name into the right ID for you. The remote is flathub unless you say otherwise.

    On the machine you are leaving, press Back up settings…. It packs every Keep settings app that is on this machine into one file; Fresh apps need no backup. Every one of them has to be closed first, and Flat says which are still open.

    Removing a row with its × is remembered. Pressing Add everything here leaves those out, so something you have taken off does not walk back on. Adding it by name from the search box puts it back for good, and Forget removals clears the lot.

    Changes save themselves as you type. To carry the list to a new machine, press Save the list… and keep the small flat-apps.json file next to the AppImage — Flat finds it on its own the first time it runs there. No backup file is needed for this; it installs the apps, not their settings.
